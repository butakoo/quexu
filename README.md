# 雀序 v0.13 · 静态本地账号版

纯 HTML、CSS 和 JavaScript 游戏。无需邮箱服务、Supabase、数据库或第三方脚本，适合 GitHub Pages 等静态托管。

每位玩家在自己的浏览器创建本地昵称和头像，自动保存各自的牌局。同一浏览器可建立多个账号并切换；重新打开网页时恢复最后使用的账号。账号可以改名、导出备份、导入备份和删除。完成对局记录保留最近20局；账号管理页显示最近10局。

本地账号没有密码保护，不是联网登录：同一浏览器的使用者可切换这些账号。不同设备或浏览器的账号互不共享。清除浏览器数据、使用无痕模式后关闭窗口、改变网站域名或仓库路径，都可能使原账号无法继续读取；使用导出备份手动迁移进度。

## 直接上传网页

请使用交付的“静态网页上传包”，解压后把里面的 **index.html、app.js、各个JS/CSS、图标和清单文件** 放到仓库根目录。该包已处理相对路径和缓存版本，不需要安装依赖或运行构建。

打开仓库 Settings → Pages，选择 Deploy from a branch、main、/(root)，保存。详细图文对应步骤见交付的《静态版上传说明》。GitHub 免费个人账号使用 Pages 时需要公开仓库；公开网页并不会包含玩家的本机账号数据。[GitHub 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)。

首次进入填写昵称创建账号，即可开局。打开商店时可先隐藏商店，再通过牌桌右上角“本地账号与存档”管理玩家。

## 修改源码和本机预览

本开发源码目录需要 Node.js 22以上，无第三方依赖。执行：

```powershell
npm test
npm run build
npm start
```

预览地址：http://127.0.0.1:4181/quexu-online/ 。预览服务器同时支持根路径与仓库子目录，便于验证 GitHub Pages。正式上传 `build` 目录里面的文件。

不要直接双击 index.html 运行：游戏模块和离线缓存需要 HTTP 或 HTTPS 地址。首次打开网页需要联网；完整加载后可离线打开已缓存的页面，是否保留缓存由浏览器管理。

## 存档和更新

- 每次操作同步写入浏览器本机存储，无云端延迟；不会把账号或牌局上传到网站仓库。
- 每个本地账号使用独立UUID存档槽；改名不会影响进度。
- 导入账号备份总是创建新账号；重名自动添加序号，原账号保留。
- 原型旧版的单局JSON存档，在创建本地账号后通过牌桌设置中的“导入存档”继续使用。
- 同账号同时打开两个页面时，检测到另一页面的新版本会暂停并提示选择，避免一般旧页面覆盖新进度。两个页面严格同时写入并不具备数据库事务保证，建议一个账号同时只在一个页面打牌。
- 保存空间不足会显示提示，保留当前未保存进度供导出或重试，不把保存失败显示为成功。
- 每个网址目录分别保存本地账号；保持域名和仓库名稳定。手动备份可以迁移到另一网址或设备。
- 更新网页文件并提交后，由托管服务重新发布；刷新或重开网页读取新代码。本次没有代替你创建仓库或发布站点。
