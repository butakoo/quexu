# 雀序 · 开发项目

当前版本 **v0.19.0**，规则版本17，存档格式4。主开发目录：`D:\游戏设计\雀序`。

纯静态麻将自走棋，一名玩家对三名电脑。手机横屏；每位玩家在自己的浏览器保存本地账号、牌局和历史记录。

## 开始开发

需要Node.js 22以上，无第三方依赖。在本目录打开终端：

```powershell
npm test
npm run build
npm start
```

预览：http://127.0.0.1:4181/quexu-online/ 。网页使用模块和离线缓存，请通过HTTP预览。

## 文件位置

| 路径 | 用途 |
| --- | --- |
| `AGENTS.md` | 后续开发对话自动读取的项目约定 |
| `docs/项目核心.md` | 已确认玩法、羁绊、计分和交互的核心上下文 |
| `docs/开发接续.md` | 当前版本、源码入口、验证及发布状态 |
| `docs/对话决策记录.md` | 规则变更顺序及被替代的早期设定 |
| `docs/项目对话使用说明.md` | 如何把目录和对话归入应用项目 |
| `dist/` | 游戏页面与逻辑源文件 |
| `scripts/`、`tests/` | 构建／预览脚本与116项自动测试 |
| `build/` | 当前可上传的完整静态网页 |
| `outputs/` | 最新及历史交付包、设计文档、截图 |
| `tools/browser/` | v0.16—v0.18浏览器验证脚本、生成器和测试牌局 |
| `archive/` | 旧Sites方案、旧独立账号方案、麻将图案参考 |

开发先读项目核心和开发接续，只修改当前dist源码。archive与旧版本压缩包均不是主开发基线。

## 更新网页

执行 `npm run build` 后，将build里的全部文件覆盖上传GitHub仓库根目录，或使用outputs最新版本上传包。仓库根目录直接放index.html、app.js等文件，包含presentation.js和trait-hints.js。页面标题应显示v0.19.0。

本次迁移没有上传GitHub或修改旧Sites站点，也没有自动建立应用中的项目归属。旧C盘工作目录保留为备份；后续开发以本D盘目录为准。迁移核对详情见 `docs/迁移核验.json`。

若新开对话，直接说：**“继续开发雀序，请先读取AGENTS.md、docs/项目核心.md和docs/开发接续.md。”**
