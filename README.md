# 雀序 · 开发项目

当前本地测试版本 **v0.28.1**（尚未发布），规则版本22，存档格式4。主开发目录：`D:\游戏设计\雀序`。

纯静态麻将自走棋，一名玩家对三名电脑。手机横屏；每位玩家在自己的浏览器保存本地账号、牌局和历史记录。

## 本机启动

在完整项目目录双击 **启动雀序.cmd**。它会检查Node.js、启动隐藏的本地服务，并打开 http://127.0.0.1:4181/quexu-online/ 。重复启动会复用现有服务。首次没有build时自动构建。

**不要双击build/index.html游玩。** 文件直开会显示启动说明；网页模块需要HTTP／HTTPS加载。纯网页上传包供网站托管，本地使用完整项目或源码包里的启动器。无需清除已有浏览器账号。

## 开始开发

需要Node.js 22以上，无第三方依赖。在本目录打开终端：

```powershell
npm test
npm run build
npm start
```

预览：http://127.0.0.1:4181/quexu-online/ 。网页使用模块和离线缓存，请通过HTTP预览。

## 道具牌（v0.26）

商店小概率出现抹、附、融，占五格之一，固定10G，不享受普通牌首免。购买后在手牌上方独立道具区显示；先把目标拖到待打区，再点击道具。抹换牌面，附补异色，融将不同牌面合成主牌＋纹路，并合并颜色、材质与已有纹路，保留最高成长。有效使用一次后消耗；抹／附／融均有独立动画与音效。
